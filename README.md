## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/alebetadie-hue/addis-alem-hospital-sbfr-odk.git
   cd addis-alem-hospital-sbfr-odk
   ```

2. **Review the Getting Started guide**:
   - See `GETTING_STARTED.md` for quick onboarding

3. **Explore the structure**:
   - Check `workflows/` for team processes
   - Review `data-collection/` for forms and templates
   - Read `implementation/` for setup instructions

4. **Access training materials**:
   - Visit `training/` for guides and FAQs

## 📊 Data Collection Overview
